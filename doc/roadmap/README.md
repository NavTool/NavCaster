# Roadmap 文档说明

本目录保存目标架构、历史计划和迭代流水。

这些文档不能直接当作当前实现事实；完成状态必须以源码、`current/` 文档和近期任务/QA/Review 记录为准。

| 文件 | 内容 |
| --- | --- |
| `architecture-v2.md` | 长期目标架构方向。 |
| `refactor-plan-v2.md` | 阶段化重构计划，旧 checkbox 不代表当前完成态。 |
| `development-plan*.md` | 早期开发计划和专项计划。 |
| `iteration-progress.md` | 迭代流水和历史验证记录。 |
